    Как настроить Zoom

    Zoom Marketplace → «+» → Build App → Server to Server OAuth App. Добавьте read scopes meeting:read:meeting:admin, cloud_recording:read:list_user_recordings:admin и cloud_recording:read:list_recording_files:admin, активируйте приложение. Введите Account ID, Client ID и Client Secret только в этой защищённой форме. Нужна облачная запись отдельных аудиодорожек участников. Проверка не сохраняет настройки.

    Хранилище
