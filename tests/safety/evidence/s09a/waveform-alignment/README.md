# Waveform zoom amplitude and onset regression

Receiving Mac validation for the reported waveform maximization / late graphical onset.
Implementation starts at `6dab9b76e0463dc67320f92c1b3ae56852b80a4e`; this follow-up
also removes the inherited PNG max-width clamp and measures actual image geometry.
The final tested HEAD, post-commit full local browser result and exact-HEAD CI link
are recorded in draft PR #36. Existing user pages were never reloaded.

## Reproduction and fix

A real 41.3-second synthetic WAV starts its 0.25-amplitude tone at 10.500 seconds.
[Before](reproduction-before.json), native overview starts at 10.499562 but the
32-second FFmpeg detail window starting at 8 seconds draws it at **11.255371**.
[After](reproduction-after.json), detail starts at **10.500000**.

The bundled showwavespic algorithm assigns integer samples per column and puts
its remainder into the last column ([upstream source](https://ffmpeg.org/doxygen/5.1/avf__showwaves_8c_source.html)).
Treating that output as uniform bins spanning the requested duration stretched
its time axis. The new shared image filter pads to an exact column multiple and
retains its true bin rate / image duration. Only the visualization is padded;
source files, playback, cuts, DSP and rendering output are unchanged.

Native overview previously used only channel 0; FFmpeg averaged/downmixed audio.
Both now use linear channel peaks, with no per-window normalization, preserving
right-only and anti-phase content. Analysis uses 48 kHz in the image path instead
of low-passing detailed windows to 8 kHz. PNG and canvas use the same 92% vertical
range. The PNG's calculated width must not be clamped by the generic img rule.
