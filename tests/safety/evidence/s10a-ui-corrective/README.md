# S10A UI corrective visual evidence

The `before/` and `after/` directories contain matched Chromium screenshots
captured from the repository-owned S10A preview server with synthetic empty
Archive data. Desktop captures use a 1280 × 900 viewport; mobile captures use
390 × 844. The search field is keyboard-focused in Archive and Editor picker
captures so the complete `:focus-visible` ring and label spacing are visible.

These screenshots are local regression evidence only. They do not represent a
production activation or real-device acceptance run.
